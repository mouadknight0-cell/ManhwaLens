ManhwaLens — Privacy Policy

Effective 2026-11-13 · Version 0.10.0

ManhwaLens captures the visible frame after Android's MediaProjection consent. OCR, bubble grouping, filtering, and overlay rendering happen on the device.

On-device mode

  • With ML Kit selected, English→Arabic translation runs on-device; no translation text or frame is sent to a network service.
  • The memory and app-private disk translation cache contains source and translated text only. It can be cleared in Settings.
  • When diagnostics are enabled, a recent capture may be kept in app-private cache for review; it is not uploaded automatically.

Optional network engines

  • Gemini: if selected with your own API key, recognized bubble text is sent to Google's Gemini API over HTTPS. Text translation does not send screenshots. The key is stored in app-private preferences and sent in the x-goog-api-key header.
  • AI cleanup: if separately enabled, cropped images of up to three bubbles and their Arabic translations may be sent to Gemini for image editing. It does not upload the full page.
  • LibreTranslate / Argos: if selected, recognized text is sent in one batch over HTTPS to the LibreTranslate URL you configure. An optional server API key is sent in the HTTPS JSON request body. ManhwaLens does not operate or control that server; the server operator's privacy and retention rules apply. Use an endpoint you trust.

The app does not log API keys or send analytics, ads, or telemetry. ManhwaLens has no user accounts and no translation server operated by the developer.

Your controls

  • Choose ML Kit for on-device translation.
  • Clear Gemini and LibreTranslate settings, including keys, from Settings.
  • Clear the translation cache or disable diagnostics in Settings.
  • Revoke system permissions or uninstall at any time; uninstall removes app-private data.

ملخص عربي

تُجرى معالجة OCR وتجميع الفقاعات على الجهاز بعد موافقة التقاط الشاشة. مع ML Kit تبقى الترجمة على الجهاز. اختيار Gemini يرسل نص الفقاعات إلى Google عبر HTTPS بمفتاحك، وخيار التنظيف التجريبي قد يرسل صورًا مقتطعة لما يصل إلى ثلاث فقاعات. اختيار LibreTranslate يرسل النص دفعة واحدة عبر HTTPS إلى عنوان الخادم الذي أدخلته، مع مفتاح اختياري في جسم JSON. لا يشغّل المطوّر خادمًا؛ تنطبق سياسة مشغّل الخادم الذي تختاره. يمكن مسح كاش النصوص والمفاتيح من الإعدادات. لا توجد تحليلات أو إعلانات أو بيانات قياس.
